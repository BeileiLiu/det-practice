# 重构产品原型

> 这是信息架构原型，用于先确认任务顺序和页面职责；视觉稿在结构稳定后细化。

## 1. 今日学习

```text
┌ 顶栏：品牌                         专项练习  模拟考试  复习记录  设置 ┐
│ 目标 125 · 距考试 21 天                                             │
│                                                                    │
│ 今天练 15 分钟                                                     │
│ 听写：漏词是最近最常见问题                  [继续今日任务]          │
│ 预计 6 题 · 完成后复练 3 个错项                                   │
│                                                                    │
│ 本周 4 天练习 │ 22 题 │ 最近表现 82% │ 待复习 7 项                 │
│                                                                    │
│ 今日路径：诊断 ✓ → 听写 2/6 → 错题复练 → 小结                     │
└────────────────────────────────────────────────────────────────────┘
```

首页主操作只有“继续今日任务”。统计优先展示可解释的练习量和正确率；练习估分另加清晰标签。

## 2. 专项答题

```text
┌ 听写 · 第 2/6 题                                      00:42  退出 ┐
│ 任务：输入你听到的完整句子                                         │
│                         [播放]  剩余 2 次                          │
│ ┌──────────────────────────────────────────────────────────────┐  │
│ │ Your response                                                │  │
│ └──────────────────────────────────────────────────────────────┘  │
│                                              [提交答案]           │
└────────────────────────────────────────────────────────────────────┘
```

题型组件只处理该题的输入和展示。会话层处理开始、超时、提交和答案快照。

## 3. 答题反馈

```text
┌ 本题表现 82%                         练习估分 105（规则 v1）         ┐
│ 参考句：The committee reached a decision after a long discussion. │
│ 你的句：The committee reach a decision after long discussion.     │
│                                                                    │
│ 漏词 1：a        词形 1：reached → reach                           │
│ 最先改：听到冠词时也要写下来                                      │
│                       [再听一次] [加入复习] [下一题]                │
└────────────────────────────────────────────────────────────────────┘
```

反馈优先展示答案证据和一个行动建议。AI 建议属于增强内容，不阻挡本地结果。

## 4. 模拟考试报告

```text
┌ 模拟考试报告 · 规则版本 2026.x                                      ┐
│ 综合练习估分 115–125             完成 47/47 · 无异常中断             │
│ Reading 78%  Listening 71%  Speaking 待评估  Writing 76%            │
│                                                                    │
│ 主要失分：听写漏词、互动口语回答过短                                │
│ 建议路径：[听写复练 8 题] → [互动口语 2 组] → [三天后再测]           │
│                                                                    │
│ 每题：题目 / 原始答案或音频 / 评分证据 / 反馈 / 复练                 │
└────────────────────────────────────────────────────────────────────┘
```

报告必须显示规则版本、完成情况和未评估维度，不能用缺失数据补成完整官方成绩。
